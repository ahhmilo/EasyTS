Before you switch
Read first
1
Register the resolution with your GPU
Windows can only switch to resolutions your graphics driver already knows. Create each stretched resolution as a custom resolution in NVIDIA Control Panel, AMD Software, or Intel Graphics Software first.
2
Set GPU scaling to Full-screen
In the same control panel, set scaling to Full-screen so the image fills the monitor. Not Aspect ratio, not Centered.
3
Turn the monitor driver off
Use the card above before you launch VALORANT. It stops Windows from pinning your display to its native aspect ratio.
4
Set VALORANT's display options
Display Mode: Windowed Fullscreen. Aspect Ratio Method: Fill.
5
Switch once you are in a match
Apply your resolution after the match has loaded. Menus and agent select can glitch at a stretched resolution. Leave EasyTS open in the background and it restores your resolution when VALORANT closes.
Fix Black Bars
Recommended for laptops
Some systems display black bars on the sides when using a custom resolution. This fix sets the display scaling to Full Panel in the Windows Registry, forcing the screen to stretch the image correctly.

⚠ Requires administrator permissions — a UAC prompt will appear.
⚠ A PC restart is required after applying.
May not work on all systems. Best results on Intel and AMD integrated graphics. NVIDIA users should use NVIDIA Control Panel → GPU Scaling → Full Screen instead.
